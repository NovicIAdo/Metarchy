
## Фаза-1 (Событие)
Действие Сервера если Ход-1: Пропустить Фаза-1 и Перейти к Фаза-2

Действия Сервера если Ход не является Ход-1:
1) Обратиться к Колода Карт Событий:
      - Если количество Карт Событий в Колоде является 0, перейти к Фаза-2
      - Если количество Карт Событий в Колоде больше 0, то выбрать наугад (от рандома) одну из Карт Событий и отобразить её Игрокам
2) Отобразить Карту Событий Игрокам

Если это Карта Событий которая сравнивает количество Ценностей у Игроков, тогда Сервер сравнивает количество указаного типа Ценности (либо сумму всех Ценностей) у каждого Игрока, и отображает Игрокам итог. Игрок с наименьшем количеством Ценности указаного типа (либо с наименьшей суммой всех типов Ценностей) получает Ценность Слава.
Действия Игроков: Нажать на кнопку Принято.
Сервер: Отображает Игроку который нажал на кнопку Принято информацию: ОЖИДАЕМ ДРУГИХ ИГРОКОВ.
После того, как все Игроки нажали на кнопку Принято, Сервер изменяет Состояние Игры:
- Добавляет одну Ценность Слава в инвентарь Игроку-победителю
После того как Состояние Игры изменилось, Сервер переходит к Фаза-2

Если два или более Игроков имеют одинаково наименьшее количество указаной Ценности (или суммы всех Ценностей), Сервер отображает Игрокам итог, и указывает какие Игроки переходят к Разрешению Конфликта.
Действия этих игроков: Нажать на кнопку Разрешить Конфликт.
Игроки с большим количеством указанных Ценностей (или суммой всех Ценностей) получают информацию: ЖДИТЕ РАЗРЕШЕНИЯ КОНФЛИКТА.
Действия Сервера: Перевести Игроков на Экран Разрешения Конфликтов между Игроками.
Сервер имеет Состояние Конфликта "Игроки не выбрали Аргументы".
Действия Игроков: Выбрать Аргумент (Камень/Ножницы/Бумага) для разрешения кофликта и нажать на кнопку ГОТОВО.
Сервер: Отображает Игроку который нажал на кнопку ГОТОВО информацию: ОЖИДАЕМ ДРУГИХ ИГРОКОВ.
После того, как все Игроки нажали на кнопку Принято, Сервер изменяет Состояние Игры:
- Добавляет одну Ценность Слава в инвентарь Игроку-победителю

Если это Карта Событий которая сравнивает количество Ценностей у Игроков, тогда Сервер сравнивает количество указаного типа Ценности (либо сумму всех Ценностей) у каждого Игрока, и отображает Игрокам итог. Игрок с наименьшем количеством Ценности указаного типа (либо с наименьшей суммой всех типов Ценностей) получает Ценность Слава.
Действия Игроков: Нажать на кнопку Принято.
Сервер: Отображает Игроку который нажал на кнопку Принято информацию: ОЖИДАЕМ ДРУГИХ ИГРОКОВ
После того, как все Игроки нажали на кнопку Принято, Сервер изменяет Состояние Игры:
- Добавляет одну Ценность Слава в инвентарь Игроку-победителю
После того как Состояние Игры изменилось, Сервер переходит к Фаза-2

Сервер: Перейти к Фаза-2

## Фаза-2 (Распределение)
Сервер имеет Состояние Игры "Все Локации пустые"

Действия Игроков: Отправить Актора в Локацию, выбрать Аргумент для Актора, добавить или пропустить добавление Ставки. Проделать это для всех четырёх Акторов.
После того как все Акторы с Аргументами распределены по Локациям, Игрок нажимает на кнопку Следующая Фаза.
После этого, Игрок уже не может изменить расположение Акторов, изменить Аргументы, изменить/убрать/добавить Ставки.

Сервер получает данные о том, в каких Локациях находятся Акторы игрока, какого типа Акторы, с какими Аргументами, и есть ли у них Ставки.

Сервер: Отображает Игроку который нажал на кнопку Следующая Фаза информацию: ОЖИДАЕМ ДРУГИХ ИГРОКОВ

После того как Сервер получил данные от всех Игроков (количество Игроков в игре может быть от 2 до 4), Сервер изменяет Состояние Игры на "Распределение Произошло":
- Для каждой Локации указано какие Игроки направили каких Акторов, с какими Аргументами, и есть ли у них Ставки
- Из Инвенторя Игроков вычитаются Ресурсы, которые были использованы для добавления Ставок
- Обновляется отображение в Глобальной Статистике

После того как Состояние Игры изменилось, Сервер переходит к Фаза-3

## Фаза-3 (Действия)
Сервер имеет Состояние Игры: Все Локации пустые.
